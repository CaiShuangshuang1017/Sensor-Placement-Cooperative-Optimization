This repository contains the main code for the study entitled “Sensor Placement for Water Distribution Systems: Leveraging Sensor Cooperation Gain to Boost Pipe Burst Detection Performance.” For additional code requests, please contact the authors.
Abstract
Pipe bursts in water distribution networks (WDNs) not only intensify water shortages but also increase contamination and road collapse risks, posing threats to public safety and urban resilience. These incidents often cause correlated pressure drops across multiple sensors, indicating a potential for cooperative sensing. Previous studies reveal that a cooperation gain system can significantly improve burst detection accuracy and spatial coverage. However, the achievable cooperation gain is highly dependent on sensor layout, and how to actively optimize cooperation gain through sensor placement remains an unresolved challenge. To bridge this gap, this study proposes a novel cooperative sensor placement algorithm (Gain System Design based Multi-Fidelity Optimization, GSD-MFO) that explicitly incorporates inter-sensor cooperation potential through a cooperation gain design module. In addition, a multi-fidelity optimization strategy is developed to balance computational cost and solution quality. Case studies on the benchmark network demonstrate that the proposed method increases network coverage and burst coverage probability by 10.13% and 10.32%, respectively, while achieving equivalent performance using 66.67% fewer sensors than the conventional method.
